# スレスパ2 ラン記録集計

Slay the Spire 2（スレスパ2）が自動で保存するラン記録ファイル（.run）を読み込んで、複数のランをまとめて集計するWebページ型のアプリです。

> **非公式ファンツールです。** Slay the Spire 2 の開発元・販売元とは一切関係ありません。

## アプリを開く
**https://okitakunai.github.io/sts2-stats/**

Chrome または Edge で開くと、すべての機能が使えます（それ以外のブラウザでも、ファイルを選んで読み込めます）。

## 特徴
- 読み込んだファイルは、あなたのブラウザの中だけで処理します。外部には一切送信しません
- このアプリがファイルに求めるのは「読み取り」の許可だけです。ゲームのファイルを書き換えることはありません
- シングルプレイと協力プレイを分けて集計します

## 対応ゲームバージョン
v0.98.1 〜 v0.111.0（Steam版）の記録で動作を確認しています。それ以外のバージョンでも読み込めますが、記録の形式が変わっている項目は「不明」と表示されることがあります。

## ラン記録ファイルの場所
```
%APPDATA%\SlayTheSpire2\steam\<SteamID>\profile（番号）\saves\history
```
探し方：
1. エクスプローラー（フォルダの画面）を開きます。
2. 上のアドレス欄をクリックし、`%APPDATA%\SlayTheSpire2` と入力して Enter を押します。
3. `steam` → 数字のフォルダ（あなたのSteamID） → `profile1` など → `saves` → `history` の順に開きます。

`.run` がラン記録です。`.run.backup` は `.run` の完全なコピーなので、このアプリは読み込みません。profile1 以外（profile2 など）にも記録がある場合があります（profile2 以降は、実際の記録ではまだ確かめていません）。

## 使い方（Windows・Chrome / Edge）
上の場所（AppData の中）は、ブラウザの安全のための制限で、アプリからフォルダとして直接選べません。そこで、付属の `copy-runs.bat` で .run ファイルだけを普通の場所にコピーしてから読み込みます。`copy-runs.bat` は、コピーが終わるとこのアプリのページ（[https://okitakunai.github.io/sts2-stats/](https://okitakunai.github.io/sts2-stats/)）を開きます。

### copy-runs.bat の入手（最初の1回だけ）
1. このページ（GitHub の sts2-stats のページ）のファイル一覧で `copy-runs.bat` を押します。
2. 右上の「Download raw file」（下向き矢印のボタン）を押して保存します。
3. 保存した `copy-runs.bat` は、分かりやすい場所（デスクトップなど）に置いておきます。

### 初回
1. `copy-runs.bat` をダブルクリックします。
   - 「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押します。
   - 黒い画面に件数が出て、.run ファイルだけがユーザーフォルダの中の `sts2-runs` フォルダ（`C:\Users\あなたの名前\sts2-runs`）にコピーされ、アプリのページが開きます。
2. アプリの「読み込み」タブで「sts2-runs フォルダを選ぶ」を押します。フォルダ選択の画面のアドレス欄に `%USERPROFILE%\sts2-runs` と入力して Enter を押し、「フォルダーの選択」を押します。
3. 読む許可の確認が出たら、「**すべてのアクセスで許可**」（毎回許可する、という意味の選択肢）を選びます。次からは、ページを開いただけで自動で読み込まれます。
   - この選択肢が初回に出るか2回目に出るか、表示の文言は、ブラウザの版によって違う場合があります（未確認）。「ファイルを表示する」「許可する」などしか出ない場合は、それを押してください。

### 2回目から
新しいランを遊んだら、`copy-runs.bat` をダブルクリックするだけです。
- 読む許可が残っていれば、ページを開いたときに新しいランが自動で読み込まれます。
- 許可が残っていなければ、「新しいランを読み込む」ボタンが目立って表示されるので、押してください（許可の確認が出ます）。

ゲームを遊ぶだけでは自動で読み込まれません。自動で読み込めるのは、Chrome か Edge で、公開ページ（[https://okitakunai.github.io/sts2-stats/](https://okitakunai.github.io/sts2-stats/)）で記憶したフォルダだけです。手元で動かしたページ（`start-server.bat` で開く 127.0.0.1）は、ブラウザの保存場所が別なので、自動では読み込まれません。

### 自動でコピーする（おすすめ・Windows のみ）
copy-runs.bat を、Windows の「タスク スケジューラ」（決まった時刻やきっかけでプログラムを動かす、Windows 標準の機能）に登録して、**10分おきに画面を出さずに自動でコピー**させます。こうすると、あなたの手間は**ブックマークからアプリのページを開くだけ**になります。管理者の権限は要りません。

1. GitHub の sts2-stats のページから、`copy-runs.bat` と `setup-auto-copy.bat` を「Download raw file」で保存します。**2つとも同じフォルダに**保存してください。
2. `setup-auto-copy.bat` をダブルクリックします。「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押します。
   - copy-runs.bat が `%LOCALAPPDATA%\sts2-stats\` にコピーされ、そこから10分おきに動くよう登録されます（タスクの名前：`STS2-copy-runs`）。
   - 登録の後に1回目が動き、結果が表示されます。
3. アプリ（[https://okitakunai.github.io/sts2-stats/](https://okitakunai.github.io/sts2-stats/)）をブックマークに入れ、初回だけ「sts2-runs フォルダを選ぶ」で `%USERPROFILE%\sts2-runs` を選び、許可の確認で「すべてのアクセスで許可」を選びます。
4. 以後は、ブックマークからページを開くだけで、新しいランが自動で読み込まれます（許可が残っていないときは、目立って表示される「新しいランを読み込む」ボタンを押してください）。

注意
- 動くのは、パソコンの電源が入っていて、あなたがログオンしている間だけです。電池で動いているときも動く設定にしています。
- 最大10分の遅れがあります。遊び終わってすぐ見たいときは、これまでどおり copy-runs.bat をダブルクリックしてください（両方を使っても、二重には数えません）。
- 最後のコピーの結果は `%LOCALAPPDATA%\sts2-stats\last-copy.txt` に1行で書かれます（日時と件数だけ）。エクスプローラーのアドレス欄にこの場所を入れると、メモ帳などで開けます。
- ゲームが書き込んでいる途中のファイルをコピーした場合は、次の回に元のファイルの方が大きければ、コピーを上書きして直します。アプリ側でも、読めなかったファイルや、前回から大きさ・更新日時が変わったファイルは、次の読み込みでもう一度読みます（同じランは二重に数えません）。
- copy-runs.bat を新しい版にしたときは、`setup-auto-copy.bat` をもう一度実行してください（自動実行の方には、自動では反映されません）。
- 止めるときは、`remove-auto-copy.bat` を保存してダブルクリックします。タスクを削除し、setup が作った2つのファイル（`%LOCALAPPDATA%\sts2-stats\` の copy-runs.bat と last-copy.txt）だけを消します。sts2-runs のランとゲームの保存先には触れません。
- 画面を出さない方法として、Windows に入っている `conhost.exe --headless`（画面を作らずにコマンドを動かす仕組み）を使っています。作者のパソコン（Windows 11）では画面が出ないことを確かめましたが、ほかの Windows の版での動きは未確認です。
- Mac には、自動でコピーする方法はまだありません（未対応）。

### copy-runs.bat がしていること
- `%APPDATA%\SlayTheSpire2\steam` の中から、すべての SteamID のフォルダと、すべての profile の `saves\history` を自動で探し、`.run` ファイルを `%USERPROFILE%\sts2-runs` へコピーします
- コピー先にまだ無いファイルをコピーします。`.run.backup` はコピーしません
- コピー先のファイルが元より小さいとき（ゲームが書き込んでいる途中にコピーしたとき）は、コピーを上書きして直します（上書きするのはコピーだけです）
- 結果を `%LOCALAPPDATA%\sts2-stats\last-copy.txt` に1行で書きます（日時と件数だけ）
- ゲームの保存先のファイルは読むだけで、変更・削除・移動は一切しません
- 新しいランが無いときは「新しいランはありませんでした」と表示して、ページを開きます
- 保存先や history フォルダが見つからないときは、理由を表示して止まり、ページは開きません
- 注意（下記）やコピーの失敗があったときは、画面を自動で閉じません。何も問題が無いときだけ、5秒後に閉じます
- 中身はテキストファイルなので、メモ帳で開いて確認できます（日本語の Windows で確実に動くよう、Shift_JIS という文字の保存方式で保存しています）

**注意が出たとき**（ここで「消して」と書いているのは、すべてコピーの `sts2-runs` の中のことです）
- 「SteamID のフォルダが〇個あります」：同じパソコンで別の Steam アカウントでも遊んだ場合です。そのまま使うと、別のアカウントの記録が混ざり、シングルの集計に他のアカウントのランが入ります。分けたい場合は、エクスプローラーで `sts2-runs` フォルダの中身を消し（ゲームの保存先ではなく、コピー先の `sts2-runs` です）、自分の SteamID のフォルダの `history` から .run だけを手で `sts2-runs` にコピーしてください。
- 「コピーの方が元より大きい」：別の profile に同じ名前のファイルがある可能性があります。ふつうは起きません。続くようなら、ゲームを終了してから、`sts2-runs` の中のそのファイルを消して、もう一度実行してください。

※ コピー先に OneDrive の中のフォルダ（「ドキュメント」など）は使わないでください。.run にはSteamIDが含まれ、OneDrive に同期されてしまいます。そのため copy-runs.bat は、OneDrive の外にあるユーザーフォルダにコピーします。

## Mac をお使いの場合（未確認）
**Mac での動作と、画面に出る文言は未確認です。** このアプリの作者は Mac で確かめていません。うまくいかない場合は、下の「別の読み込み方法」を使ってください。

### ラン記録ファイルの場所（未確認）
```
~/Library/Application Support/SlayTheSpire2/steam/<SteamID>/profile（番号）/saves/history
```
の可能性が高いです（`~` はホームフォルダのことです）。

開き方：
1. Finder を開き、Command＋Shift＋G（「フォルダへ移動」）を押します。
2. `~/Library/Application Support/SlayTheSpire2` を貼り付けて Return を押します（「ライブラリ」フォルダはふだん隠れているので、この方法で開きます）。
3. `steam` → 数字のフォルダ → `profile1` など → `saves` → `history` の順に開きます。

見つからない場合は、Finder で「SlayTheSpire2」を検索してください。

### copy-runs.command（Mac 用。未確認）
Windows の `copy-runs.bat` と同じく、すべての SteamID・すべての profile の `.run` だけを `~/sts2-runs`（ホームフォルダの中の sts2-runs）にコピーし、最後にアプリのページを開きます。コピー先にまだ無いファイルだけをコピーし、元のファイルは読むだけで、変更・削除・移動は一切しません。表示や止まり方も Windows と同じですが、終わった後のターミナルの画面は自動で閉じません。

初回：
1. このページのファイル一覧で `copy-runs.command` を押し、「Download raw file」で保存します。
2. ファイル単体でダウンロードした場合は、「実行してよい」という印が消えているため、最初に次の操作が必要です。「ターミナル」（アプリケーション → ユーティリティ）を開き、`chmod +x `（最後に半角スペース）と入力し、保存した `copy-runs.command` をターミナルの画面にドラッグ＆ドロップして Return を押します。
3. `copy-runs.command` をダブルクリックします。開けない場合は、「システム設定」→「プライバシーとセキュリティ」の下の方にある「このまま開く」を押します。古い macOS では、右クリック →「開く」でも開けます。
4. ページが開いたら、「sts2-runs フォルダを選ぶ」を押し、ホームフォルダの中の `sts2-runs` を選びます（Command＋Shift＋G で `~/sts2-runs` と入力しても開けます）。読む許可の確認では、Windows と同じく「すべてのアクセスで許可」を選ぶと、次から自動で読み込まれます（Chrome の場合。未確認）。

2回目から：新しいランを遊んだら、`copy-runs.command` をダブルクリックするだけです。

`copy-runs.command` がうまく開けない場合は、「ターミナル」に次の1行を貼り付けて Return を押しても、同じようにコピーできます（最後に、コピー先にある .run の件数が表示されます。ページは自分で開いてください）。
```
mkdir -p ~/sts2-runs && for f in ~/Library/Application\ Support/SlayTheSpire2/steam/*/profile*/saves/history/*.run; do [ -e ~/sts2-runs/"${f##*/}" ] || cp -p "$f" ~/sts2-runs/; done; ls ~/sts2-runs/*.run | wc -l
```

Safari はフォルダの記憶に対応していないため、自動読み込みはできません。Safari では「.run ファイルを選ぶ」かドラッグ＆ドロップで読み込んでください（Chrome なら Windows と同じように使えます）。

## 別の読み込み方法（Chrome・Edge以外のブラウザ、または copy-runs を使わない場合）
- **.run ファイルを選ぶ**：「.run ファイルを選ぶ」を押し、開いた画面のアドレス欄に `%APPDATA%\SlayTheSpire2` と入力して history フォルダまで進み、Ctrl＋A で全部選んで「開く」を押します。この方法なら AppData の中からも直接選べます
- **ドラッグ＆ドロップ**：.run ファイルや、.run の入ったフォルダを、画面の枠の中にドラッグ＆ドロップします

どちらも毎回ファイルを選ぶ必要がありますが、読み込み済みのランは自動で飛ばします。

## データの保存（バックアップ・復元・CSV）
読み込んだランや設定は、このブラウザの中に保存されます。ブラウザのデータを消すと失われるので、時々書き出しておくと安心です。「読み込み」タブの下の方にある「データの保存」で操作します。

### 書き出す目的
- **自分用（復元用）**：SteamIDとニックネームを本物のまま含めます。**他の人に渡したり、インターネットに上げたりしないでください。**
- **共有用**：SteamIDを架空の値に置き換え、ニックネームは含めません。

### 書き出す内容
- **全部（ランを含む）**：ランも含めます。ラン数が多いと数十MBになります。
- **設定だけ**：日本語名辞書・縛りチャレンジ・ニックネーム・協力プレイの「自分」の設定だけです。ランは、copy-runs.bat でコピーした sts2-runs フォルダから読み込み直せば元に戻せます。

### 復元
1. 「JSONを読み込む（復元）」を押し、書き出したファイルを選びます。
2. 中身の件数が表示されるので、よければ「OK」を押します。

今のデータに足し合わせます。同じランが架空のIDで保存されていて、新しく読んだ側（復元ファイルや .run）が本物のIDなら、本物のIDに置き換わります。

### CSV
「ラン一覧をCSVで書き出す」で、1行1ランのCSV（Excelで開けるファイル）を保存できます。各画面の表も、表の上の「CSVで書き出す」で書き出せます。CSVには、SteamIDとニックネームは含めません。

## 自分のパソコンで動かす（開発中の確認用）
Python が入っている場合は、`start-server.bat` をダブルクリックするだけで、ブラウザにアプリが開きます。
- 黒い画面は、アプリを使っている間は閉じないでください（最小化は大丈夫です）
- 終わるときは、黒い画面を閉じるか Ctrl＋C を押します
- すでに起動している場合は、ブラウザで開くだけになります
- このパソコンの中（127.0.0.1）からしか見られません

PowerShell で起動する場合：
1. PowerShell を開きます。
2. `cd "このフォルダの場所"` を実行します。
3. `python -m http.server 8765 --bind 127.0.0.1` を実行します。
4. Chrome か Edge で `http://127.0.0.1:8765` を開きます。
5. 終わったら PowerShell で Ctrl＋C を押します。

## GitHub Pages での公開手順（自分で公開する場合）
このアプリは、ファイルを置くだけで動くので、GitHub Pages（GitHub の無料のWebページ公開機能）で公開できます。
1. GitHub にサインインし、右上の「＋」→「New repository」を押します。
2. 「Repository name」に名前（例：`sts2-stats`）を入れ、「Public」を選びます。README などは追加せず、「Create repository」を押します。
3. 作ったリポジトリに、このアプリのファイル（`index.html`・`css`・`js` など）を送ります（Git を使う場合は `git push`）。
4. リポジトリの「Settings」→ 左の「Pages」を開きます。
5. 「Build and deployment」の「Source」を「Deploy from a branch」にし、「Branch」で `main`、フォルダで `/ (root)` を選んで「Save」を押します。
6. 数分待つと、ページの上に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が表示されます。
7. 更新するときは、変更したファイルを同じリポジトリに送り直すだけです（数分で反映されます）。

公開URLで開いたアプリと、自分のパソコンで動かしたアプリは、ブラウザの保存場所が別になります。データを移すときは「データの保存」で「自分用・全部」を書き出して、移した先で読み込んでください。
